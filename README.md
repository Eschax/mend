mend is one patch tool for every AI edit format: it applies unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON edits to a file tree, with three-tier fuzzy matching and all-or-nothing writes.

## Run it

```sh
node main.ts fix.diff
```
